1. Open your EXISTING AIT Campus Connect / AIT Pune Campus Achievement & Participation Portal project folder as the active workspace in Antigravity. Do not start a new blank website.
2. Copy or unzip this bundle inside that workspace under a private temporary folder such as research_inputs/ (or attach its files to the Antigravity chat if supported).

4. Tell Antigravity: 'The research_inputs folder has all input files. Modify my existing project in-place, preserve current features and data, verify sources, and implement the complete prompt.'
5. Grant permission for code modifications, database migrations and local development runs only after reviewing requested sensitive operations. 6. Before any production deployment, review Antigravity's test logs, schema migrations, claimed verification of AY 2026-27 appointments and any pending data conflicts.
